Sistema web de **facturación electrónica** para la gestión de tiendas, clientes y documentos fiscales, adaptable a cualquier tipo de negocio.

---

## Características

- Gestión de **tiendas** y su información fiscal.  
- Administración de **clientes**.  
- Creación y seguimiento de **documentos electrónicos** (facturas, notas de crédito, etc.).  
- Visualización de **resúmenes y reportes de ventas**.  
- Control de acceso basado en **roles de usuario** (superadmin, admin, usuario).  
- Integración con sistemas de **firma electrónica**.  
- Validación de datos fiscales y protección de información sensible.  

---

## Tecnologías

- **Backend:** Laravel 10 (PHP 8.2)  
- **Base de datos:** MySQL 8  
- **Frontend:** Blade, Bootstrap, Select2  
- **Contenedores:** Docker (opcional para desarrollo y despliegue)  
- **Control de versiones:** Git / GitHub
